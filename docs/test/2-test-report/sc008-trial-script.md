# SC-008 五人试用脚本（待真实参与者）

**状态**：试用未完成。仓库内没有五位真实用户的独立试用记录。  
本文件只提供主持人脚本和空白记录表。代理、模拟用户、自动化用例都不能计入样本。  
执行人不得代填成功/失败，也不得由本代理自行联系、邀请或招募第三方。

## 样本

- 人数：不少于 5 名目标用户（设计师或制作同学），每人独立完成一次。
- 成功：无阻断错误（无 `SIZE_MISMATCH` 等），并且得到可打开的 PPTX。
- 成功率 = 成功人数 / 参与人数，目标 ≥ 90%。
- 2026-11-17 起，本阶段发布不再因样本不足而阻断。未做真人试用时仍写「试用未完成」，不记通过。

## 主持人准备（真人执行）

1. 准备同一份标准演示稿：统一尺寸，至少包含文本、矩形、图片。
2. 准备可登录的 Penpot（`enable-feature-plugins`）和已安装的 Canvory 插件。
3. 向每位参与者只说明下面的步骤，不代为点击导出。
4. 参与者互不协助。主持人只记录参与者当场说出的结果。

## 参与者步骤

1. 打开标准演示稿。
2. 打开 Canvory 插件，范围选「全部」，模式选「自动优化」。
3. 先看预检。若出现阻断错误，停在这里并告知主持人，不要改稿再试。
4. 若无阻断，导出并下载 PPTX。
5. 用自己常用的办公软件打开该文件，说明是否出现修复提示、文本是否还能编辑。
