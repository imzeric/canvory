# Test Report — 测试报告归档

本目录存放单次测试执行的详细报告。`0-tested.md` / `1-defect.md` 仅保留索引。

## 命名约定

```text
YYYYMMDD-<用例或批次ID>-<简短描述>.md
```

示例：

- `20261117-AT-A-cdm-dual-output.md`
- `20261120-QA-PPTX-04-compat-matrix.md`

## 报告最小结构

1. 元信息：日期、执行人、环境、构建/提交  
2. 范围：覆盖用例列表  
3. 结果摘要：通过 / 失败 / 跳过  
4. 详细步骤与证据（截图、文件路径、日志）  
5. 结论与后续（缺陷 ID、是否可发布）
