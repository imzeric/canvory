## 1. 产品一句话

统一画布与内容模型，生产演示文稿、网页、绘本、动画与互动教学内容的多形态视觉创作平台。  
PPTX 是第一个切入点，HTML 是正式交付形态，CDM（Canvory Document Model）是长期核心资产。

## 2. Storyboard（叙事板）

| 镜号 | 阶段 | 用户看见什么 | 系统在做什么 | 出口物 | 目标周期 |
|------|------|--------------|--------------|--------|----------|
| S0 | 架构与 PoC | 画一页即可导出可编辑 PPTX | CDM；Monorepo；Adapter；Core；首个 Exporter | PoC PPTX | 1–2 周 |
| S1 | PPTX 正式版（本规格范围） | 预检、富文本/图形、模式选择、兼容、大文件任务 | 完整 PPT 相关能力 + 最小 HTML 护栏 | 可商用 PPTX 闭环 | 3–6 周 |
| S2+ | 后续 | HTML 发布 / Studio / 动画 / 多形态 | 见架构文档 Phase 2–5 | 平台化 | 另案 |

**第一阶段定义（本草案）：S0 + S1，覆盖 PPT 相关全部功能；最小 HTML 只读仅作架构验收，不做发布产品化。**

## 3. 第一阶段模块分解（Epic → Story → Feature）

编号规则：`E` Epic / `S` Story / `F` Feature。执行态任务以 `docs/shipping/0-to-dos.md` 为准；本处为规划分解。

### Epic E1 — 统一内容模型与工程基座

支撑所有导出的「单一真相」与可协作工程结构。

| Story | 目标 | Features |
|-------|------|----------|
| **S1.1 定义 CDM 初版** | 可手工构造、可校验的演示文稿内容 | F1.1.1 Document/Scene/Node/Asset 语义与必填字段<br>F1.1.2 schemaVersion 与样例文档<br>F1.1.3 动画/交互占位（只定义、不实现编辑） |
| **S1.2 工程骨架** | 包边界清晰，后续可替换创作源 | F1.2.1 Monorepo 应用/包边界（model/core/adapters/exporters）<br>F1.2.2 共享校验与单位换算约定<br>F1.2.3 黄金样例目录约定 |

### Epic E2 — 创作源接入（Penpot → CDM）

短期用 Penpot 画，但提取结果必须是 CDM。

| Story | 目标 | Features |
|-------|------|----------|
| **S2.1 创作环境就绪** | 团队能稳定打开画布并安装导出入口 | F2.1.1 自托管 Penpot 可用<br>F2.1.2 插件安装/权限最小化<br>F2.1.3 设计师画板规范（尺寸/命名/字体）发布 |
| **S2.2 页面与基础元素提取** | 矩形、文本、图片稳定进入 CDM | F2.2.1 画板 → Scene<br>F2.2.2 文本/矩形/图片 Node<br>F2.2.3 坐标、旋转、叠放顺序 |
| **S2.3 扩展元素提取** | 覆盖正式版元素面 | F2.3.1 椭圆/线条/简单路径<br>F2.3.2 分组/组件展开<br>F2.3.3 富文本分段（runs）<br>F2.3.4 演讲者备注读写<br>F2.3.5 资源去重与 Asset 引用 |

### Epic E3 — PPTX 导出核心

CDM → 可交付演示文稿文件。

| Story | 目标 | Features |
|-------|------|----------|
| **S3.1 最小可编辑导出（PoC）** | 三要素即可下载可用 PPTX | F3.1.1 文本框原生导出<br>F3.1.2 基础形状原生导出<br>F3.1.3 图片对象导出<br>F3.1.4 浏览器内下载 |
| **S3.2 完整元素映射** | 正式版视觉/可编辑平衡 | F3.2.1 描边/圆角/透明度/外阴影<br>F3.2.2 背景纯色与底图<br>F3.2.3 备注写入幻灯片<br>F3.2.4 字体映射表 |
| **S3.3 导出模式** | 高保真 / 可编辑优先 / 自动优化 | F3.3.1 模式选择 UI/配置<br>F3.3.2 按模式调整降级阈值<br>F3.3.3 默认自动优化 |
| **S3.4 导出范围与排序** | 部分页、排序规则 | F3.4.1 全部/选中页<br>F3.4.2 位置序/名称序 |

### Epic E4 — 预检、降级与质量可见性

禁止静默失真。

| Story | 目标 | Features |
|-------|------|----------|
| **S4.1 降级分级引擎** | L0–L3 判定一致 | F4.1.1 原生/近似/栅格化/跳过规则<br>F4.1.2 栅格化分辨率与上限<br>F4.1.3 跳过规则（隐藏/空/零尺寸） |
| **S4.2 预检面板与报告** | 导出前可知、导出后可查 | F4.2.1 按页汇总与明细<br>F4.2.2 导出 JSON/可读报告下载<br>F4.2.3 中文文案 |
| **S4.3 兼容与回归** | 达到阶段质量门槛 | F4.3.1 跨软件打开矩阵<br>F4.3.2 黄金样例回归<br>F4.3.3 文本可编辑率/误差/耗时度量 |

### Epic E5 — 导出运营能力（版本与大文件）

| Story | 目标 | Features |
|-------|------|----------|
| **S5.1 文档版本** | 可恢复后再导出 | F5.1.1 保存版本快照<br>F5.1.2 恢复历史版本<br>F5.1.3 版本与导出内容一致性 |
| **S5.2 后台导出任务** | 大文档可靠交付 | F5.2.1 任务创建与状态<br>F5.2.2 结果下载与失败重试<br>F5.2.3 超阈值自动建议转后台 |

### Epic E6 — 架构护栏（最小 HTML + 验收）

满足宪法，防止 CDM 被 PPTX/Penpot 绑架。

| Story | 目标 | Features |
|-------|------|----------|
| **S6.1 最小只读展示** | 同 CDM 可核对 | F6.1.1 读取 CDM 渲染页结构<br>F6.1.2 文本与相对布局核对视图 |
| **S6.2 架构验收用例** | A/B（及 C 的回归意识） | F6.2.1 同文档双输出对照<br>F6.2.2 手工 CDM 不经 Penpot 导出<br>F6.2.3 报告归档到 `docs/test/` |

## 4. 优先级切片（建议交付顺序）

| 切片 | 包含 | 可演示价值 |
|------|------|------------|
| MVP-1 | E1 + E2.1–E2.2 + E3.1 | 能导出可编辑 PPTX |
| MVP-2 | E2.3 + E3.2 + E4.1–E4.2 | 正式元素面 + 预检可信 |
| MVP-3 | E3.3–E3.4 + E4.3 + E6 | 模式/兼容/架构护栏达标 |
| MVP-4 | E5 | 版本 + 大文件任务（与 MVP-3 **同一发布包**必达，不可拆出） |

规格用户故事映射：US1→MVP-1；US2/US3→MVP-2；US4/US6→MVP-3；US5→MVP-4（P1 必达）。  
已澄清：MVP-3 与 MVP-4 必须同一发布包；缺一则第一阶段不算完成。

## 5. 范围边界

### 进入第一阶段

- CDM、Penpot 接入、PPTX 全映射与三模式、预检报告、备注、字体映射、版本、后台导出、跨软件兼容、最小 HTML 只读与架构验收 A/B。

### 明确不做（第一阶段）

- 自研 Studio、完整 HTML 发布/分享、动画/转场原导出、绘本/白板、PPT 母版深度、竖排文字、改造 Penpot 源码、微服务拆分。

## 6. 架构验收（不可降级）

| ID | 描述 | 通过标准 |
|----|------|----------|
| A | 一份文档，两个输出 | 同 CDM → PPTX + 最小 HTML，结构与布局一致 |
| B | 不经 Penpot 构建 | 手工 CDM 仍可导出 PPTX（及最小 HTML） |
| C | 新场景类型可扩展 | 增加 Scene 类型不破坏既有 PPTX 导出核心（回归） |
