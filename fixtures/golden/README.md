- SC-001 分母：样例合集中 `type=text` 且未 L3 的节点数  
- SC-001 分子：其中导出报告为 L0 或 L1 的节点数

- SC-003：LibreOffice 无头渲染 PPTX→PDF/PNG 后测中心点；命令写入 `metrics.md`
